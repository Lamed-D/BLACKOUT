# 실습 가이드
[실행 안내](run.md)에 따라 공개 포털을 엽니다. 접속 로그에서 로그인 결과를 판독하고, 게시글 수정에 필요한 권한 검사를 찾고, 데이터 복구에 사용할 백업을 선택합니다. 각 사례 아래의 해설을 열어 판단 근거를 확인하세요.

기존 게시판은 board 프로필로 실행합니다. 관리자는 Compose 로그로 웹 요청과 DB 기동 상태를 확인할 수 있습니다.
공개 포털의 **Docker 실습 환경 선택**에서 Flask와 PHP의 실행 방법과 관찰 항목을 확인하세요. PHP는 실제 응답 헤더와 세션 설정을 비교합니다.
